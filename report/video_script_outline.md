## 规范

- **可比性**：两次对比同起点、同释放速度（发射滑台同档）、同采样率；各 3 次取平均并在字幕注明。
- **不夸大**：应用价值段只写"可作为 / 可用于"；场景不写"已装备 / 已应用 / 世界首创"。
- **术语统一**：电涡流制动 / 定子 / 动子 / 铁芯线圈 / 随动式通电 / 双模复用；模块名按"平台控制 / 采集 / 电流 / 变流 / 编码器"五模块口径，与技术文档、答辩口径一致。
- **数字有出处**：4 kHz、500 ns、20 路、30 线圈、24 V、tick 1 kHz 均在文档正文；制动时间与距离只填实测。
- **字幕**：单行 ≤ 18 字，底部两行内；单位与数字间半角空格。
- **音频**：旁白峰值 -6 dB，BGM -26 LUFS，保留 20 % 环境声。
- **合规**：轨交/机构示意图自绘，不剪他人素材；录屏不露无关桌面与他人信息。
