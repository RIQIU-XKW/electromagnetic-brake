# 协议与单位

TCP 服务端：`192.168.1.10:7`（DHCP 时地址看串口），RAW API，所有 lwIP 调用只在 net 任务里。

帧定界方式：**TCP 字节流，收到一块就整块处理**。文本命令按整行比较；单字节命令按字节扫描。
所有处理函数都必须**把整条报文扫完**再返回（曾经"认出一条就 return"导致同报文里的 `0xA0/0xA1`
被丢弃）。

## 下发：文本命令

| 命令 | 回复 |
|---|---|
| `PING` | `pong` |
| `STATUS` | 一行总状态：`zynq \| led=… \| ip … \| net=… \| pwm en=… oc=… \| cmds=… \| ls=… \| ocEv=… ocLt=… ocNw=… \| brk=on/30%/500ns rpt=…` |
| 其它 | `unknown (N bytes); try …` |

## 下发：单字节命令（在整条报文里扫这些字节）

| 字节 | 含义 |
|---|---|
| `0xA0` | 制动使能：开全局调制（桥仍关着） |
| `0xA1` | 启动制动：五路桥同时打开，用当前占空比 |
| `0xA2 / 0xA3 / 0xA4` | 预设占空比 30% / 50% / 70% |
| `0xA5` | 停止制动：五桥全关 + 关全局调制 + 清过流锁存 |
| `0xD0` | 用当前档位发射小车 |
| `0xD1..0xD6` | 选 1..6 档（记住）并立刻发射 |
| `0xE0 / 0xE1 / 0xE2` | 开始采样 / 停止采样 / 查采样状态 |
| `0xF0..0xF5` | 全灭 / 慢呼吸 / 标准 / 快呼吸 / 查灯状态 / 全亮 |
| `0xF6..0xF9` | 点亮 LED0..LED3 |
| `0xFA..0xFD` | 熄灭 LED0..LED3 |
| `0xFE <n>` | 共享频率 = n×10 Hz（n = 1..100 → 10..1000 Hz） |
| `0xFF <m>` | 四路使能掩码 m = 0..15 |
| `0xAA / 0xAB / 0xAC` | 查按键状态 / 软复位 PS / 重启 TCP 服务端 |
| `0xE3` | **电流零点标定**：采 2 s 当前引脚电压作为各路归零电压（要求采样中 + 制动关闭） |

`0xFE`、`0xFF` 吃掉**同一报文**的下一个字节。命令表在 `app/inter_app.c` 的 `Inter_App_Commands[]`：
先精确名，再按顺序问各模块的兜底处理函数（返回 1 = 认领）。

## 下发：制动参数帧（4 字节，必须同一次 write）

```
[0xDA][占空比高字节][占空比低字节][0xDB]     占空比 0..70 %(整数)   —— 五路桥同步
[0xDC][死区高字节][死区低字节][0xDD]         死区 0 或 100..10000 ns
[0xBA][电流低字节][电流高字节][0xAB]         电流指令 0..15000 mA   —— 5 桥共用
```

⚠ 前两条**大端**（高字节在前），电流帧**小端**（低字节在前，按现场给的 `{0xBA, 低, 高, 0xAB}`）。
⚠ 帧头不能用 `0xAA`：它既是按键命令、又是按键上报广播。

异常回复：

| 情况 | 回复 |
|---|---|
| 帧头对、第 4 字节不是帧尾 | `brake ERR: bad frame tail (0xDA needs 0xDB, 0xDC needs 0xDD)` |
| 帧被拆到下一个报文 | `brake ERR: frame truncated (need head + 16bit + tail)` |
| 占空比 > 70 | `brake ERR: duty must be 0..70 (%)` |
| 死区 1..99 ns | `brake ERR: dead time must be 0 (duty 0) or >= 100 ns` |
| 电流帧帧尾不对 | `current ERR: frame must be [0xBA][lo][hi][0xAB]` |

三条硬限制：**占空比 ≤ 70%**、**斩波时死区 ≥ 100 ns**、**占空比 0 时死区必须为 0**。
上位机（`widget.cpp` 的 `kDutyMaxPercent` / `kDeadMinNs` / `applyDutyDeadCoupling`）和下位机
（`brake_ctl_app.h` 的 `BRKCTL_DUTY_MAX` / `BRKCTL_DEAD_MIN_NS`）各自把关。

## 两条控制链路：占空比模式 vs 电流闭环

| | 占空比模式 | 电流闭环 |
|---|---|---|
| 命令 | `0xA1` + `0xDA`/`0xDC` 帧 | `0xBA` 电流帧 |
| 谁在算 | `app/brake_ctl_app.c`（5 ms 任务） | `service/Algorithm_module/`（10 ms 任务 `curloop`） |
| 输出 | 五桥同一个占空比 | 5 个独立 PID，各写各的占空比 |

规矩是**最后一条命令说了算**：

- 收到电流指令 > 0 → 闭环接管：自己开全局调制、开五桥，并把五桥死区设成 **100 ns**（只设一次）。
- `0xA5` / 过流 / 收到占空比帧 → 闭环立刻放手（`Svc_CurLoop_Stop`）。**这条是安全项**：
  闭环每 10 ms 一拍，只要目标 > 0 就会自己开桥，不按住它的话"点了停止制动却关不掉"。
- 放手之后闭环**不再写占空比**（缓存去重），不会把占空比模式刚设好的值抹成 0。
- 上位机在 PWM 栏发的 `0xDC` 死区帧任何时候都有效，闭环不会每拍刷回 100 ns。


## 上报

1. **文本回话**（只回发起命令的那个客户端）：一行或几行 ASCII，如
   `brake 0xA1 started: 5 bridges ON`、`samp E0 sampling ON …`、`led mask=0x05 on=0,2 freq=100Hz state=normal`、
   `key ready=1 armed=1 | KEY1(MIO10/E9)=up n=0 | …`
2. **遥测文本广播**（所有客户端，10 ms 一行，仅采样+广播打开时）：

   ```
   DATA <秒> <i1>..<i5 A> <动子速度 mm/s> <母线电压 V> <动子位移 mm> <激光电压 V>
   例: DATA 1.234 12.345 11.891 12.402 12.010 11.950 123.456 24.310 240.123 0.938
   ```

   固定 10 个数，全部 3 位小数：第 2..6 = 线圈 1..5 **电流(A)**；第 7 = **动子速度(mm/s)**；
   第 8 = **母线电压(V)**（11:1 还原）；第 9 = **动子位移(mm)**；第 10 = **激光引脚电压(V)**（排障，不画）。
   字段位置是固定契约，新增字段只能加在末尾。⚠ 第 7 个在 2026-11 之前是"CH6 引脚电压"，语义变了。
3. **二进制广播**（2 字节）：

   | 报文 | 含义 |
   |---|---|
   | `[0xB0][掩码]` | 光幕状态变化，bit i = 第 i+1 路被遮挡（**只上报，不触发制动**） |
   | `[0xC0][源掩码]` | 过流出现/恢复，bit i = 第 i+1 个桥 |
   | `[0xAA][掩码]` | 按键变化，bit0 = KEY1 按着，bit1 = KEY2 按着 |

## 单位与标定

| 量 | 公式 | 改动位置 |
|---|---|---|
| 线圈电流 | `I[A] = (1.5·V − 2.5)·10` ⇔ `I[mA] = 15·(V[mV] − 零点mV)`；零点默认 1667 mV、灵敏度 15 A/V，±30 mA 死区归 0 | `SVC_ADS_COIL_MA_PER_MV` / `SVC_ADS_COIL_ZERO_MV`；现场用 **0xE3** 标定零点（制动关、采样中） |
| 母线电压 | `Vbus = CH5 引脚电压 × 11` | `service_ads.c` 的 `SVC_ADS_VBUS_DIVIDER` |
| 动子位移 | 两点标定 `x = x1 + (x2−x1)/(y2−y1)·(V−y1)`；实测 `0.732 V→0 mm`、`1.143 V→480 mm`，即 **1 mV ≈ 1.17 mm** | `service_ads.h` 的 `SVC_ADS_LASER_X1_MM/X2_MM/Y1_V/Y2_V` |
| 动子速度 | `v = |Δx|/Δt`（Δt=10 ms，取绝对值），仅"上一拍+当前拍都 TRACK"才算；低通 + 20 mm/s 死区 | `SVC_ADS_LASER_SPEED_ABS` / `_SPEED_DEADBAND_MMS` / `_DISP_ALPHA` / `_SPEED_ALPHA` |
| eMMC CSV | `t_ms,i1..i5,vbus,speed,x_mm,laser_mv`（speed = 动子速度 mm/s、x_mm = 位移 mm、laser_mv = 原始激光电压 mV） | `service_emmc.c` + `bsp/emmc/emmc.c` 的行校验（9 个逗号） |

序列掩码没使能的通道报 `0`（表示"没采"），不会按 0 V 折算成 −25 A。
