## PWM 引脚（来源：`src/constraints/pwm.xdc` + `data/pin_assignment.xlsx`）

```
桥(CH)  AH=Q1   BH=Q2   AL=Q3   BL=Q4   | 使能 EN1/EN2  | 过流 MAX ILD
1        W10     V10     V8      W9     | W6     V6     | V11
2        Y12     R14     Y6      V16    | T10    T11    | Y13
3        W8      V13     U13     T15    | T12    U12    | T14
4        V17     P14     V18     P16    | T16    U17    | P15
5        W16     W19     W18     U18    | R16    R17    | U19
```

- 原理图位号（同一路内）：`Q1 = LLC_PRI PWM1`、`Q2 = PWM2`、`Q3 = PWM3`、`Q4 = PWM4`；`CH1..CH5` = 第 1..5 个桥。
- 每桥 **W10/V10 是两个上管（Q1/Q2）、V8/W9 是两个下管（Q3/Q4）**。
- `pwm.xdc` 的 C 列球号才是约束用的；`引脚分配.xlsx` 的 D 列是**转接板丝印**，两者不一定同名
  （如 `gate_en_0[2]` 球号 T10、丝印 R1）。
- 这颗 `xc7z020clg400-2` 只有 bank 13 / 34 / 35 能当 PL IO；写不存在的球名会让 DRC UCIO-1 挡住位流。

## pwm_axi_ip 寄存器

| 偏移 | 名字 | 说明 |
|---|---|---|
| 0x00 | CTRL | `[0]` GLB_EN 全局调制；`[1]` INV_PWM 翻转全部 20 路 |
| 0x04 | PERIOD | 周期（aclk 周期数）；写 0 = 输出全低 |
| 0x08..0x18 | DUTY0..4 | 每桥比较值（一个桥两条腿共用一个） |
| 0x1C..0x2C | DEAD0..4 | `[15:0]` leg A 死区、`[31:16]` leg B 死区 |
| 0x30 | PWM_EN | `[9:0]` 10 个半桥 gate 使能；**`[19:10]` 每桥 2 位的腿 B 模式** |
| 0x38 | ID | 固定 `0x50574D31` |
| 0x3C | STATUS | `[0]` GLB_EN 镜像 `[1]` PERIOD_OK `[2]` CNT_ZERO `[3]` ANY_EN `[4]` OC_NOW `[5]` OC_LATCHED `[12:8]` OC_SRC `[31:16]` 计数器 |
| 0x40..0x50 | PHASE0..4 | 每桥相位偏移 |

### 腿 B 模式（`PWM_EN[19:10]`，每桥 2 位）

| 值 | 含义 | 电气效果 |
|---|---|---|
| `0` | NORMAL 对角驱动（复位默认） | 对角导通，`V = (2D−1)·Vbus`，电流双向、纹波大 |
| `1` | leg B 静态低（BL 通、BH 断） | leg A 斩波：`+Vbus` / 0 V，慢衰减 |
| `2` | leg B 静态高（BH 通、BL 断） | 配 leg A 静态低 → `−Vbus`，快衰减 |
| **`3`** | **leg A 静态高 + leg B 斩波（本项目制动用）** | AH 常开/AL 常关；BL 在 `[dt, D)` 导通。负载 = `D/PERIOD · Vbus`，单向电流、慢衰减 |

`mode_b = 3` 是 2026-10-30 在本仓库新增的（`src/rtl/pwm_axi_ip_1_0/hdl/pwm_h_bridge.v`）：

```verilog
wire        mode_a_static = (mode_b == 2'd3);
wire [31:0] duty_a_eff    = mode_a_static ? 32'hFFFFFFFF : duty;   // AH 常开 / AL 常关
wire [15:0] dead_a_eff    = mode_a_static ? 16'd0        : dead_a; // 静态腿不吃死区
```

静态腿会忽略自己的死区（IP 强制置 0）。
⚠ **改了这个 HDL 必须重综合**，否则板上位流里没有 mode 3，写 3 会退化成 mode 0（对角驱动）。

### 写 `PWM_EN` 的铁律

只改 `[9:0]`，其余位原样写回。历史上 `Pwm_SetHalfBridgeEnable/SetBridgeEnable/SetAllHalfBridges/Pwm_Stop`
里用 `&= 0x3FF` 或直接写 `0x3FF/0`，把模式位清掉 → 现象是"启动制动后又变回对角驱动"。

### 使能脚 `gate_en`（EM）是**低有效**

引脚 **低 = 开输出，高 = 关断**。IP 顶层把 `PWM_EN` 的使能位取反后输出，所以：

- 寄存器语义仍是 "1 = 使能"（固件 `Svc_Pwm_SetBridgeEnable(b, 1)` = 开输出）；
- 复位（使能位 0）与过流封锁时引脚为**高** = 关断 ✓；
- 2026-10-30 之前是直通驱动：结果"1 = 使能"实际把输出关掉，过流保护又把 EM 拉低 = 反而开启。

### 过流保护

RTL：`oc_br_off = ~oc_n | oc_src`（实时电平 OR 粘滞锁存）。某个 `oc_n[i]` 拉低 → 该桥 4 管 ~2 ns 内关断，
其余桥继续；引脚恢复高只去掉实时项，**粘滞位仍锁住**；清粘滞 = `CTRL.GLB_EN` 做一次 0→1 边沿
（`Svc_Oc_Acknowledge()`，注意它会顺手打开调制，关断流程里要在它之后再关调制）。
`APP_PWM_OC_AUTO_ACK = 0`（人工确认），monitor 的 `Svc_Pwm_AlarmPoll()` 只打印。

频率固定 4 kHz（PERIOD 12500 @ 50 MHz），默认死区 500 ns（25 周期）。

## ADS8688

- 通道：CH0..CH4 = 线圈 1..5 电流传感器，CH5 = 母线，CH6 = 激光，CH7 = 备用。
- 器件命令：`NO_OP 0x0000` / `RST 0x8500` / `AUTO_RST 0xA000` / `MAN_Ch_n 0xC000+n*0x0400`；
  命令帧 = 命令 16 位 + 补一帧 NO_OP（4 字节）。程序寄存器写 `[(addr<<1)|1, data]`，
  读 `[addr<<1, 0, 0]`，**收 3 字节、Rx[2] 才是数据**。
- 换算：双极性 `mV = (raw−32767)·跨度/65535`；单极性 `mV = raw·跨度/65535`。
- 量程码：`0`=±10.24 V `1`=±5.12 V `2`=±2.56 V `5`=0..10.24 V `6`=0..5.12 V。
- 一次 `PsSpi_Transfer()` = 一个 CS 周期 = 一帧；每帧之间 CS 必须拉高再拉低。
- 序列掩码 `SVC_ADS_SEQ_MASK`（0xFF = 8 路全采）决定采哪几路、一轮读几帧。

## 激光测距（CH6，动子位移/速度）

传感器 **ST-M2 系列小型点激光**（手册 V0.1.0.1），模拟输出档位 **4~20 mA**，板上用
**100 Ω 取样电阻**变成电压进 CH6（0..5.12 V 档，一个 LSB ≈ 0.078 mV）。

**判定阈值**（= 手册表 4-4/4-5 的余量/错误值 × 100 Ω，改档位就要重算）：

| 手册电流 | ×100 Ω | 含义 | 状态 |
|---|---|---|---|
| 3.0 mA | 300 mV | 读数**无效**（错误值最小） | **LOST** |
| 3.8 mA | 380 mV | 小于映射起点的**余量值** | 过渡防抖区（保持状态） |
| 20.2 mA | 2020 mV | 大于映射终点的**余量值** | 仍算 TRACK |
| 21.0 mA | 2100 mV | 读数**无效**（错误值最大） | **LOST** |

**两点标定**（现场实测，`service_ads.h` 的 `SVC_ADS_LASER_X1_MM/X2_MM/Y1_V/Y2_V`）：

```
0.732 V -> 0 mm      1.143 V -> 480 mm
x[mm] = x1 + (x2-x1)/(y2-y1) * (V[V] - y1)     即 1 mV ≈ 1.17 mm
```

- 状态机：`<300` / `>2100` = LOST；`380..2020` = TRACK；中间两段保持状态；切换需**连续 3 拍**。
- 测速：**上一拍和当前拍都 TRACK** 才算 `v = |Δx|/Δt`（Δt = 10 ms）；任何跳变清位置缓存 +
  滤波器，所以不会跨丢失段算假速度；丢失时报 0。
- 平滑：位移一阶低通(0.35) → 差分 → 速度一阶低通(0.30) → **死区 20 mm/s**。
  取绝对值会把零均值噪声整流成正的，死区是让"动子停住"时速度干净读 0 的唯一办法。
- ⚠ 分辨率天花板就在标定上：411 mV 跨 480 mm ⇒ 1 LSB ≈ 0.09 mm，10 ms 差分量化噪声 ±9 mm/s。
  想更细：① 把传感器"映射起点/终点"收窄到实际行程（480 mm 铺满 1.6 V）；② 改读它的
  **RS485 数字量**（16 bit 直接给 mm，板上正好有一路 RS485，协议见手册 4.2/4.5）。
- 传感器侧还要确认："数据滤波"的滑动平均宽度设成 **1**（= 不滤波），否则位移被平滑过，
  差分出来的速度会被削弱还带滞后。

## eMMC

- 自动录制：卡挂上 + 采样在跑就录，**没有任何录制命令**。
  数据流 `ads 任务 → Svc_Emmc_OnSample() → QEmmc(128 条) → emmc 任务 → 512 B 暂存 → 1 s f_sync`。
- 盘上 CSV **10 列**：`t_ms,i1..i5,vbus,speed,x_mm,laser_mv`
  （speed = 动子速度 mm/s、x_mm = 动子位移 mm、laser_mv = 原始激光电压 mV）。
  行校验按"**9 个逗号**"判结构，老记录（8/9 列）回读时会被当成废行丢掉。
- 自动选盘：`1:/`（eMMC，SD1）不可用时退 `0:/`（SD 卡槽）。
- 回读接口 `Emmc_ReadLines()` 还在，但目前**没有命令入口**（原来那套 `EMCxxx` 已删）。
- 挂载只在上电做一次；开机后才插卡要重启板子。

## 按键

KEY1 = 软复位 PS（不重载 PL 位流；从 JTAG 启动会停在 boot ROM）；KEY2 = 重启 TCP 服务端。
20 ms 轮询 + 3 次消抖，上电 3 s 内不响应，只在"消抖后跳到按下"那一次动作。
